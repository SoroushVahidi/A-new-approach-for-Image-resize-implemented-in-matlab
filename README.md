# An Alternative Image-Resizing Method (MATLAB)

> Historical undergraduate project (2020), kept for reference.

**What this is.** A simple image-resizing (interpolation) method written in MATLAB and compared against MATLAB's built-in `imresize`. The comparison numbers are in `Compare.xlsx`.

## Report

- S. Vahidi. *A New Method for Resizing the Images.* Unpublished report, 2022. DOI: [10.13140/RG.2.2.15756.59521/1](https://doi.org/10.13140/RG.2.2.15756.59521/1)

## Files

| File | What it is |
|---|---|
| `Code for imresize.rar` | MATLAB source (archive) |
| `sample images.rar` | Test images (about 460 KB) |
| `Compare.xlsx` | Comparison of this method with MATLAB `imresize` on the sample images |

## Run

Extract both archives, open the code folder in MATLAB (the Image Processing Toolbox may be needed), and run the resize script on an image from `sample images`.
